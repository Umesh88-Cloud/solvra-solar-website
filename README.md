
# SOLVRA — Solar Energy Website

SOLVRA is a modern static website created as an assignment for **Qiro Tech Innovation Pvt. Ltd.**.

The website presents solar energy solutions through a clean, interactive, and visually engaging interface focused on the idea of **Clean Energy · Smart Future**.

## Features

- Responsive solar energy website
- Cinematic hero section with background video
- Interactive navigation
- Solar energy solution cards
- Hover-based image reveal effects
- Animated impact statistics
- Interactive 3D solar panel using Three.js
- Smooth GSAP animations and scroll effects
- About and Get Started sections
- Modern dark-green and lime solar-themed design

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Three.js
- GSAP
- GSAP ScrollTrigger
